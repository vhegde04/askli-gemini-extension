# Askli for Gemini CLI

Askli turns product questions into AI-moderated customer interview studies and evidence-backed Decision Reviews.

The extension connects Gemini CLI to Askli's hosted MCP server and adds customer-research guidance. It can create and clarify studies, review plans, report progress, and retrieve findings linked to interview evidence.

Askli preserves the customer's stated audience and constraints. It does not silently broaden unsupported audiences or present qualitative research as population-level certainty. Participant setup and any paid services stay in Askli's web app.

## Install

```sh
gemini extensions install https://github.com/vhegde04/askli-gemini-extension
```

Restart Gemini CLI after installation. The first Askli tool use opens a browser so you can sign in securely.

## Example

> I am considering a foldable divider that prevents children sharing a hotel bed from fighting over space and blankets. Use Askli to identify the right customer audience and create a research plan to test whether parents would want this.
